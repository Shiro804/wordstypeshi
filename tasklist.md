# Phase 8: BatasPairs – Memory Card Matching Game Implementation
# Konzept: Klassisches Memory-Spiel. Karten liegen verdeckt auf einem Grid. Spieler decken 2 Karten auf — bei Match bleiben sie offen, sonst werden sie wieder verdeckt. Ziel: alle Paare finden. Scoring basiert auf Zeit und Anzahl der Fehlversuche. Emoji-Icons als Kartenmotive (sprachunabhängig). Schwierigkeitsgrade: Easy (4x3=12 Karten/6 Paare), Medium (4x4=16 Karten/8 Paare), Hard (5x4=20 Karten/10 Paare).

Init: generate shuffled grid of emoji pairs from seed using createSeededRandom. Logic: flip card → if 2 flipped → check match → if match mark as matched, else flip back after delay flag.
